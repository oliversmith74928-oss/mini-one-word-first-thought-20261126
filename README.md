Entry for the [One Word, First Thought](https://make.fun/bounty/u-0xkianno-one-word-first-thought-106abaf8) bounty on make.fun.

`main.py` (Python standard library only) writes exactly one word to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`):

**petrichor** — the smell of rain on dry earth.

The output is deterministic: byte-identical across runs.
